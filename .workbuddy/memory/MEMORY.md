# 项目记忆

- “游戏拆解”栏目采用“文章列表卡片 -> 阅读器全文”的结构，不在列表页直接铺全文。
- 从 docx 导入文章时必须保留全文，不可摘要替代正文；图片按文中顺序导入并保留。
- 阅读器样式约定：顶部避免多余留白，章节标签使用黑色，整体保持报纸感排版。
- “游戏拆解”文章封面优先使用用户单独提供的 banner；若未提供，再考虑使用文内首图作为卡片封面。
- 游戏拆解栏目导语/摘要应尽量保留用户原有文风，不要擅自改写成过于概括的站内简介。
- 游戏拆解卡片封面图必须限制在卡片框内显示；不同长宽比的封面统一用裁切方式适配，不允许溢出边框。
- 首页统计预览需与左侧栏目保持同一套分类口径（同人作品 / 原创作品 / AVG作品 / 游戏拆解），数量应从实际数据自动同步，不再手填。
